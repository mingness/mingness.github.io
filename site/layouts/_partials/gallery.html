Clicking one opens PhotoSwipe (https://photoswipe.com), a popup viewer with previous/next buttons, keyboard arrows, swipe and pinch-zoom on phones. Without JavaScript the thumbnails are still plain links to the large images. Called from works/page.html with the page as context: {{ partial "gallery.html" . }} Which images, in what order, and their captions come from a "gallery" list in the page's front matter: gallery: - src: street_reflection.jpg # file name inside gallery/ (required) title: Street reflection # shown in the popup caption description: Charcoal and ink. # shown in the popup caption Only the images in the list are shown, in list order. "title" ($entry.title | default "") "description" ($entry.description | default "") ) }} {{ else }} {{ warnf "%s: gallery image %q not found in gallery/" $.File.Path $entry.src }} {{ end }} {{ end }} {{ else }} {{ range .Resources.Match "gallery/*" }} {{ $images = $images | append (dict "img" . "title" "" "year" "" "description" "") }} {{ end }} {{ end }} {{ with $images }}
